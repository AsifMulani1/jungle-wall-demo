# Jungle Wall 3D: demo

Prototype of the café drawing wall: a child colours an elephant or rhino, and it walks into a living 3D jungle wearing their colours.

Open `index.html` through any static web host (GitHub Pages, Netlify, Vercel, Cloudflare Pages). It does not work when opened straight from disk, because the browser blocks the model files from loading.
